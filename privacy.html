Privacy Policy

Gimic Uploader is a private tool used only by the owner of the YouTube channel The World Unfolded.

What it accesses

With the owner's permission, it uses the YouTube Data API to upload the owner's videos to the owner's own channel, set their titles, descriptions and thumbnails, and confirm which channel it is signed in to. It does not read or change anything else.

What it stores

The sign-in token Google issues is stored only on the owner's own server so uploads can run on a schedule. No other personal data is collected or stored.

Sharing

No data is sold, shared with or transferred to anyone. Google user data is used only for the uploads described above.

Revoking access

Access can be removed at any time from myaccount.google.com/permissions.
